# 个人主页和公共主页有什么区别？
**个人主页**
用于分享个人信息、兴趣以及与亲友建立联系。它具有详细的隐私控制选项，您可以决定哪些内容仅限好友可见。您必须使用真实姓名创建个人主页，且一个主页只能由一个人管理。

**公共主页**
是为企业、品牌、艺术家、公众人物或组织设计的公开空间，用于与关注者和潜在买家互动。公共主页默认公开，任何人都可以关注。主页名称应代表企业或品牌，且支持多人按权限共同管理。**您必须拥有一个个人主页才能创建或管理公共主页。**

**核心区别对比**
- **管理权限**：个人主页仅限本人使用；公共主页支持**多人按权限管理**。
- **隐私设置**：个人主页可设置**仅限好友**；公共主页旨在**面向公众**。
- **功能工具**：公共主页提供更强大的品牌推广、广告投放和受众分析工具

# 业务资产组有哪几种权限，分别有什么权利？
- 完全访问权限
	- 拥有资产组合完全访问权限的人员可以管理设置、人员、工具和业务资产，并可能具备删除资产组合等高风险权限。
	- 风险较高，仅应分配给必须管理整个业务资产组合的贵司内部负责人。
- 部分访问权限
	- 拥有资产组合的部分访问权限的人员只能负责分配给他们的任务和业务资产。基本访问权限是添加到资产组合的每位人员获得的默认访问权限。
- 高级选项（Advanced options）
	- 页面可能提供财务等额外权限。是否出现及可分配范围以当前页面为准，仅在工作确有需要时开启。

# 业务资产组合的 临时访问权限是什么？
**临时访问权限允许您为他人提供限时（3 到 75 天）的业务资产组合基础访问权限，到期后权限会自动撤销。**
这种权限非常适合短期合作，例如临时聘请人员协助处理特定任务。以下是临时访问权限的关键点：
**核心特点**：
- **限时性**：您可以设置 3 天到 75 天的有效期。
- **自动撤销**：在到期日当天的午夜，该人员的访问权限会自动失效，并从业务资产组合及分配的所有资产中移除。
- **权限限制**：拥有临时访问权限的人员仅限于“基础访问权限”。他们无法获得“完全控制权”，也无法管理财务信息或应用集成。

# 业务资产组合包括哪些东西
一个业务资产组合可以包含以下资产：
- **Facebook公共主页**
- **Instagram账号 / Threads账号**
- **广告账户**
- **商品目录**
- **数据集、Meta Pixel（像素代码）、应用及其他可添加资产**
- **人员和合作伙伴**：贵司可以添加内部协作人员，并给他们分配不同资产的权限；也可以添加合作伙伴（例如谷雨云或贵司授权的其他服务商），让其按需要访问资产。

# 公共主页与小组有什么区别
公共主页（Page）是贵司的官方展示窗口，小组（Groups，也称“社群”）是成员围绕特定主题交流的空间。在 B2B 业务中，公共主页用于建立品牌形象和发布内容，小组可用于问答、讨论和维护已合作买家关系。

|维度|公共主页（Page）|小组（Groups）|
|---|---|---|
|定位|企业的官方身份，类似于官网。|兴趣或行业交流中心，类似于论坛。|
|互动方式|以单向发布为主，粉丝评论为辅。|以双向讨论为主，鼓励成员之间相互交流。|
|可见性|默认公开，所有人都能搜索并查看。|可选择公开或私密，能够控制内容的可见范围。|
|主要功能|运行广告、展示产品、查看成效分析。|开展问答、分享资料、维护成员关系。|
|受众关系|关注者（粉丝），关系相对疏远。|成员，关系更紧密，参与度更高。|

# 什么企业适合建立小组
- **产品具有技术门槛**：如果您的产品（如工业机械、精密仪器、新型材料）需要专业的操作指导或技术支持，社群可以作为您提供售后服务和技术交流的中心。
- **交易决策周期长**：B2B 业务通常涉及大额订单，买家需要长期观察。社群能让潜在客户在下单前通过观察您与其他成员的互动，建立对您工厂实力的信任。
- **行业有持续讨论的话题**：如果您的行业有频繁的行情波动、技术更新或政策变化（如光伏能源、跨境物流、电子元器件），建立一个行业资讯分享群能吸引大量精准买家。
- **拥有核心代理商或分销商**：您可以建立私密社群，专门用于管理海外代理商，发布最新的产品报价、促销政策和培训资料。
- **追求高客户留存率**：如果您希望客户不仅是“一锤子买卖”，而是成为品牌的忠实拥护者，社群是沉淀这些老客户的最佳场所。
# 哪些情况下不建议建立小组
- **缺乏专人维护和互动**：如果贵司无法稳定回复成员、更新内容和清理垃圾信息，小组可能长期无人维护，并影响访客对贵司专业度的判断。
- **产品标准化且缺少讨论主题**：如果买家几乎没有技术、应用或行业问题，建立小组可能难以持续吸引成员。
- **运营资源有限**：如果公共主页的日常发帖和询盘回复尚未理顺，建议先集中资源运营公共主页。
- **无法及时处理公开反馈**：公开小组中的反馈对成员可见。如果贵司尚未建立处理问题和违规内容的流程，一对一沟通可能更合适。
- **只计划发布广告**：如果小组只用于重复发布报价和广告，成员可能退出或举报内容。
