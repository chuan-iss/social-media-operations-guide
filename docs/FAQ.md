# 个人主页和公共主页有什么区别？
**个人主页**
用于分享个人信息、兴趣以及与亲友建立联系。它具有详细的隐私控制选项，您可以决定哪些内容仅限好友可见。您必须使用真实姓名创建个人主页，且一个主页只能由一个人管理。

**公共主页**
是为企业、品牌、艺术家、公众人物或组织设计的公开空间，用于与粉丝或客户互动。公共主页默认公开，任何人都可以关注。它不需要真实姓名，且支持多人共同管理并分配不同的权限角色。**您必须拥有一个个人主页才能创建或管理公共主页。**

**核心区别对比**
- **管理权限**：个人主页仅限本人管理；公共主页支持**多名管理员**。
- **隐私设置**：个人主页可设置**仅限好友**；公共主页旨在**面向公众**。
- **功能工具**：公共主页提供更强大的品牌推广、广告投放和受众分析工具
