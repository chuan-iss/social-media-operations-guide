# 社媒客户教程

本目录由谷雨云（Gooeyun）编写，面向使用谷雨云服务的企业客户，帮助企业从零完成账号搭建、主页装修、日常运营、询盘承接和数据复盘。

## 称呼说明

为避免“客户”同时指教程读者和社媒受众，本站所有教程统一使用以下称呼：

| 称呼 | 具体指谁 |
| --- | --- |
| **谷雨云 / 我们** | 本套教程的编写方和服务方，即谷雨云。 |
| **您** | 正在阅读并按照教程操作的人，通常是贵司账号负责人或运营人员。 |
| **贵司** | 购买或使用谷雨云服务的企业，也是 Facebook 公共主页和其他社媒资产的实际所有方。 |
| **潜在买家** | 在社媒上了解贵司产品，并可能发起询盘或建立业务联系的人。 |
| **访客** | 正在浏览贵司主页或内容的人；访客可能进一步成为潜在买家。 |
| **协作人员** | 经贵司授权，参与主页、内容、消息或广告管理的员工或外部服务人员。 |

除引用平台原文或解释特殊场景外，后续教程不单独使用“客户”指代上述角色。教程中的“您”和“贵司”始终指谷雨云的客户，不指贵司的潜在买家。

## 阅读说明

请按照每个平台目录中的编号顺序操作。界面可能因设备、地区、语言和平台更新略有变化，应以实际页面为准。

每篇教程默认直接使用以上简称，不再重复解释角色。如对某个称呼有疑问，请返回本页查看。

## 文档维护约定

- 文件名使用两位数字作为顺序前缀，例如 `01-教程名称.md`。
- 站内链接使用相对 Markdown 链接，兼容 Obsidian，并便于后续迁移到 MkDocs 或 Sphinx。
- 教程图片放在对应平台的 `assets/` 目录中。
- 图片文件名建议使用“教程编号-步骤编号-内容”，例如 `02-01-创建入口.png`。
- 每篇教程只解决一个任务，并保留“上一步、专题目录、下一步”导航。
