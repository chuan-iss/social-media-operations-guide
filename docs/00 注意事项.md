# 新号注意事项
**先养号 7-14天建立真实身份，再逐步开通商业功能。**
不要在注册后 24-48小时内就创建公共主页、投广告或频繁加好友/发链接。
**第一阶段：防止新号被封 - 注册后 0-14天**
这是最关键的时期，系统会重点审核你的账号是否真实。
- **完善真实身份**：
	- 使用真实姓名、头像（真人照片）、生日，绑定手机号和邮箱并开启双重验证。不要使用虚拟号或频繁更换设备/IP。
- **模拟正常用户行为**：
	- 前 3-5 天只做普通用户会做的事 -每天登录1-2次，浏览动态、点赞、评论、添加2-3个认识的朋友，关注几个感兴趣的公共主页。模拟真实用户行为。
- **稳定网络环境**：
	- 固定使用一个干净、稳定的网络和设备登录，不要频繁切换IP或使用多人共享的代理。
- **绝对不要做的事**：
	- 一天内大量加好友、加群、发相同内容或链接
	- 使用同一设备/IP 注册或登录多个新号
	- 名字频繁修改、使用品牌名作为个人账号名（个人账号必须是真人）
	- 新号前1-2周不要创建广告、不要大量加好友、不要频繁发布营销内容或外部链接。系统对新号的营销行为非常敏感。

作为刚注册的新账号，你现在最重要的目标是先养号、建立信任，再开始推广，避免被系统误判为异常账号而被封。
